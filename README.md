📌 Overview
Interactive Power BI dashboard analyzing HR employee
attrition, satisfaction, demographics and performance
across 1,470 employees.

📄 Dashboard Pages
| Page | Focus |
|---|---|
| 1 — HR Overview | KPIs · Attrition Summary |
| 2 — Attrition Analysis | Who is leaving & why |
| 3 — Demographics | Age · Gender · Education |
| 4 — Satisfaction | Scores · Performance · Salary |
| Tooltip | Hover detail on all visuals |

🧮 DAX Measures (23 Total)
- HR KPIs · Attrition Analysis
- Satisfaction · Performance

📈 Key Insights
- Attrition Rate: 16.12% (237 employees)
- Overtime attrition: 30.5% vs 10.4% with no overtime
- Attrited employees earn $1,800 less than active employees
- 299 high-risk active employees (low satisfaction)
